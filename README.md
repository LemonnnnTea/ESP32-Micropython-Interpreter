# MicroPython Web IDE (基于 WebSocket)

这是一个超级轻量级的 MicroPython Web IDE，专为 ESP32 和 ESP8266 等微控制器设计。

它仅由两个文件组成：
1.  `main.py`: 运行在 ESP32 上的 MicroPython 后端服务器。
2.  `index.html`: 你在电脑浏览器中打开的前端 IDE 界面。

通过本项目，你可以在浏览器上实现与 MicroPython 开发板的实时交互，包括**文件管理**、**代码编辑**和**REPL 终端**。

## ✨ 功能特性

* **实时 Python 终端 (REPL)**: 直接在网页上执行 MicroPython 代码，并立即看到 `print` 输出。
* **文件管理器**: 实时浏览、新建、读取、保存和删除开发板上的文件。
* **网页代码编辑器**: 直接在浏览器中编辑 `.py` 文件。
* **一键运行**: 直接运行当前编辑器中的所有代码，方便调试。
* **轻量级**: 对设备资源占用极小，纯粹的前后端分离。
* **易于部署**: 无需安装任何电脑端软件，仅需一个浏览器。

## 🔧 环境要求

* **硬件**: 一块支持 MicroPython 的 ESP32 或 ESP8266 开发板。
* **软件**:
    * 开发板已刷入 MicroPython 固件。
    * 一个用于上传 `main.py` 的工具 (如 Thonny, ampy 等)。

## 🚀 快速上手指南

按照以下步骤来启动你的 Web IDE：

### 步骤 1: 配置并上传后端 (ESP32)

1.  **配置 WiFi**:
    打开 `main.py` 文件，修改文件最上方的 WiFi 配置为你自己的网络：
    ```python
    # WiFi配置
    SSID = "你的WiFi名称"
    PASSWORD = "你的WiFi密码"
    ```

2.  **上传文件**:
    使用 Thonny IDE 或其他工具，连接到你的 ESP32 开发板。将修改后的 `main.py` 文件**上传到开发板的根目录**。

3.  **运行后端**:
    上传完成后，按下开发板上的 `RST` (重置) 按钮。开发板将自动连接 WiFi 并启动 WebSocket 服务器。

4.  **获取 IP 地址**:
    (推荐) 保持 Thonny 与开发板的 USB 连接，在 REPL 串口中你会看到类似以下的输出，请**记下这个 IP 地址**：
    ```
    WiFi连接成功!
    IP地址: 192.168.1.10
    ...
    服务器运行在: 192.168.1.10:8266
    ```
    *(如果你没有 Thonny，你也可以登录路由器后台查找名为 `ESP32-WebIDE` 或类似设备来获取 IP。)*

### 步骤 2: 打开前端界面 (电脑)

1.  **打开网页**:
    在你的电脑上，**直接用浏览器 (如 Chrome, Firefox) 打开 `index.html` 文件**。 (注意：直接双击本地文件打开即可，不需要 Web 服务器)。

2.  **连接设备**:
    在网页的“连接设置”框中，输入你刚才记下的 IP 地址，格式为 `ws://[IP地址]:8266`。
    例如: `ws://192.168.1.10:8266`

    3.  **点击“连接”**。当状态显示为“已连接”时，你就成功了！

### 步骤 3: 开始使用！

* **执行代码**: 在底部的“Python终端”输入框中输入 `print('Hello, MicroPython!')`，然后按回车或点击“发送”。
* **查看文件**: 点击“刷新文件列表”按钮，开发板上的 `main.py` 和其他文件会显示在上方。
* **编辑文件**: 点击文件列表中的任意文件 (如 `main.py`)，其内容会自动加载到“文件编辑器”中。
* **保存文件**: 在编辑器中修改代码后，确保“文件名”输入框正确 (如 `test.py` 或 `main.py`)，然后点击“保存文件”。
* **运行文件**: 在编辑器中写好代码 (例如算法测试程序)，**点击“运行文件”按钮**，编辑器内的所有代码将被发送到 ESP32 上执行，输出会显示在终端中。

## 💡 工作原理

本项目利用 WebSocket 协议实现浏览器与 ESP32 之间的全双工通信。

1.  `main.py` 在 ESP32 上扮演一个 WebSocket **服务器**。它会监听特定的命令 (如 `LIST`, `READ:main.py`, `SAVE:test.py:content...` 等)。
2.  `index.html` 是一个 WebSocket **客户端**。它通过发送这些特定命令来请求操作。
3.  当 `main.py` 收到无法识别的命令时 (例如 `print('hello')` 或一整段脚本)，它会将其作为原始 Python 代码，通过 `exec()` 在安全的环境中执行，并将所有 `print()` 输出通过 WebSocket 实时传回浏览器终端。
